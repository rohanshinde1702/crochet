🧶 CozyLoops Documentation

Official installation guide, architectural reference, and administrator documentation for the CozyLoops full-stack e-commerce platform.

⚡ React 19 + Vite 🎨 Tailwind CSS v4 🟢 Node.js & Express 🍃 MongoDB Database 🌓 Dark & Light Studio

🌟 1. Overview & Features

CozyLoops is a modern, high-conversion full-stack e-commerce web application designed for handcrafted artisans, fashion boutique creators, and physical/digital store owners.

🛍️ Storefront Features:

  • Artisanal Home & Shop Catalog: Dynamic category filtering, sorting (price, rating, newness), inventory stock indicators, and SKU lookups.
  • Interactive Product Details: Image preview, rating system, customer reviews, yarn material breakdown, and multi-channel social sharing (WhatsApp, Instagram, Twitter/X).
  • Handcrafted Craft Journal / Blog: Articles with reading time estimation, category filters, comment threads, and spotlight featured stories.
  • Shopping Bag & Checkout: Real-time cart calculations, free shipping threshold progress, local storage sync, and multi-step delivery forms.
  • Smart Contact Us: Automatically routes customer messages to the dynamic support email configured in the Admin Panel.
  • Customer Profile: Address book, active order status tracking, and account security.

⚡ Executive Admin Studio (`/admin`):

  • Executive Analytics Dashboard: Real-time KPI metrics, monthly revenue trend chart, category sales distribution progress bars, store health metrics, bestsellers leaderboard, and live MongoDB audit activity stream.
  • Dark & Light Theme Mode: 1-click header switcher and settings preferences.
  • Dynamic Store Settings: Manage Support Email, Phone, WhatsApp Number, Studio Address, Working Hours, and Social Media links with whole-store live propagation.
  • Recycle Bin: Soft-delete protection with 1-click restore for products and blog stories.

🛠️ 2. Tech Stack & Requirements

Layer Technology Purpose
Frontend React 19 + Vite Lightning-fast client rendering & hot module reloading
Styling Tailwind CSS v4 + Framer Motion Modern responsive design, animations & dark mode tokens
Backend Node.js + Express.js RESTful API service with route controllers & middleware
Database MongoDB + Mongoose ODM Document database for products, categories, orders, users, blogs
Authentication JWT + Bcrypt.js + OTP Secure token auth, hashed passwords, and 6-digit email OTPs
Mailing Nodemailer (Gmail SMTP) Automated contact inquiry delivery & verification codes

System Prerequisites:

  • Node.js: v18.0.0 or higher (Download Node.js)
  • MongoDB: Local MongoDB Community Server or free cloud MongoDB Atlas cluster
  • npm: v9.0.0 or higher

🚀 3. Installation & Setup Guide

Step 1: Extract Project Files

# Unzip the package into your desired directory
cd crochet

Step 2: Backend Configuration

# Navigate to backend
cd backend

# Install dependencies
npm install

# Copy environment variables template
cp .env.example .env

Open backend/.env in your code editor and configure your values:

PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/crochet
JWT_SECRET=your_super_secret_jwt_key_2026

# Administrator Email
ADMIN_EMAIL=admin@cozyloops.com

# SMTP Email Configuration (Gmail App Password)
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_16_character_app_password

Step 3: Seed Real Demo Data

Run the built-in multi-model seeder to automatically populate products, categories, demo orders, customers, and blogs:

node seeder.js
Database Seeded: You will see ✅ All Real Datasets Successfully Seeded to MongoDB!

Step 4: Start Backend Server

npm run dev
# Server running at: http://localhost:5000

Step 5: Frontend Configuration & Launch

# Open a new terminal window and navigate to frontend
cd ../frontend

# Install frontend packages
npm install

# Start Vite Development Server
npm run dev
# App running at: http://localhost:5173

📧 4. Email / SMTP Configuration

CozyLoops uses Nodemailer to send OTP verification codes and route customer messages from the Contact Us page.

Setting up Gmail SMTP (Free):

  1. Go to your Google Account Security Settings.
  2. Enable 2-Step Verification.
  3. Search for "App Passwords" (or go to App Passwords).
  4. Create a new app password named CozyLoops.
  5. Copy the 16-character generated code and paste it in backend/.env: 
    EMAIL_USER=your_gmail@gmail.com
EMAIL_PASS=abcdefghijklmnop

⚡ 5. Executive Admin Studio

Access the admin portal at http://localhost:5173/admin. Sign in with the default admin credentials:

Default Admin Login:
Email: admin@cozyloops.com
Password: Password@123

Dedicated Admin Modules:

  • /admin: Analytics Command Center with revenue bar charts and KPI metrics.
  • /admin/products: Catalog manager with inventory counters, filters, and CSV export.
  • /admin/categories: Collection organization with custom emoji icons.
  • /admin/orders: Live order fulfillment with 1-click status dropdowns.
  • /admin/customers: Customer directory with lifetime spend metrics.
  • /admin/blogs: Story manager with spotlight toggles.
  • /admin/recycle-bin: Soft-delete bin for 1-click recovery.
  • /admin/settings: Whole-store brand and contact information control.

🌓 6. Dark & Light Theme System

The Admin Studio includes full Dark Mode and Light Mode styling.

  • Header Quick Toggle: Click the ☀️ / 🌙 button in the top navbar for immediate theme switching.
  • Settings Appearance Selector: Choose between visual theme cards in /admin/settings.
  • Persistent Storage: Saves theme state in localStorage under adminTheme.

🔄 7. Store Settings & Social Links Sync

When you update your Support Email, Contact Phone, WhatsApp Number, Studio Address, Working Hours, and Social Media Profiles in /admin/settings:

  1. Settings are saved to MongoDB via PUT /api/settings.
  2. The global SettingsContext automatically synchronizes across all storefront pages without page reload.
  3. The Footer, Contact Us, and Product Detail pages immediately reflect the new links and details.

📡 8. REST API Reference

Method Endpoint Access Description
GET /api/products Public Fetch active product catalog
POST /api/products Admin Create new product
DELETE /api/products/:id Admin Soft-delete product to Recycle Bin
GET /api/orders Public / Admin Fetch customer orders
PUT /api/orders/:id/status Admin Update order fulfillment status
GET / PUT /api/settings Public / Admin Get and update global store configurations
POST /api/contacts Public Submit contact message & dispatch email

🌐 9. Production Deployment Guide

Frontend Deployment (Vercel / Netlify):

  1. Push your code to GitHub.
  2. Import the frontend folder to Vercel or Netlify.
  3. Build Command: npm run build
  4. Output Directory: dist

Backend Deployment (Render / Railway / VPS):

  1. Deploy the backend folder to Render or Railway.
  2. Set environment variables from your .env in the hosting dashboard.
  3. Start Command: node server.js

❓ 10. Troubleshooting & FAQs

Q: MongoDB connection error on start?

Make sure your MongoDB server is active or update MONGO_URI in backend/.env with your MongoDB Atlas connection string.

Q: Emails are not sending?

Ensure you created a 16-character Gmail App Password (not your standard Gmail login password) and pasted it in EMAIL_PASS.

Q: How do I change the default currency?

Update currency in Admin Studio → Settings or in backend/models/Setting.js.
