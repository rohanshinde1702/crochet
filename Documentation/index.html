1. Introduction

Thank you for purchasing CozyLoops! CozyLoops is a modern, lightweight, and responsive React template designed specifically for handcrafted crochet creators, boutique yarn stores, handmade craft shops, and independent artisans.

Ready Out of the Box: CozyLoops is built to be 100% functional standalone. It includes structured seed datasets and browser localStorage persistence, meaning you can test all storefront and admin features right away without setting up a backend database.

Main Features:

  • Artisan Storefront: Hero slider, category filters, product search, sorting (price, rating), stock indicators, and badges.
  • Product Details Page: Image preview, rating counter, material composition breakdown, care guide, and social sharing.
  • Handcrafted Journal / Blog: Tutorials with reading time calculator, tags, and interactive comments.
  • Cart & Wishlist: Slide-out shopping bag drawer, free shipping threshold calculator, and persistent wishlist.
  • Executive Admin Studio (/admin): Analytics dashboard, catalog manager, category manager, order fulfillment status, customer directory, blog manager, soft-delete recycle bin, and store settings.

3. Installation & Local Setup

Follow these steps to run the template locally on your computer:

Prerequisites:

Make sure you have Node.js (v18.0.0 or higher) installed.

Step 1: Install Dependencies

Open your terminal, navigate to the frontend folder, and run:

cd frontend
npm install

Step 2: Start Development Server

npm run dev

Once started, open your browser and visit: http://localhost:5173

Admin Panel Access: To view the Admin Dashboard, navigate to http://localhost:5173/admin in your browser.

4. Building for Production & Deployment

1. Generate Production Bundle

To compile the template for production, run:

npm run build

Vite will create an optimized, minified dist/ folder containing static HTML, CSS, JavaScript, and images.

2. Deploying to Hosting Providers

Platform Build Command Publish Directory
Vercel npm run build dist
Netlify npm run build dist
GitHub Pages npm run build dist
Apache / cPanel Upload the contents of the dist/ folder to your server's public_html/ directory.

5. Changing Logo, Brand & Colors

Changing the Brand Name & Contact Information:

You can change the store name, email, phone number, WhatsApp, and social media links directly in src/data/settings.js, or dynamically via the Admin Panel at /admin/settings.

Primary Color Palette:

The template uses clean CSS color variables and utility tokens:

Color Role Hex Code Usage
Brand Primary #6C2C12 Primary buttons, headings, accent badges
Brand Pink #F88897 Secondary buttons, price badges, highlights
Light Background #FFF5F5 Warm background tints, promo cards
Admin Accent #2563EB Admin dashboard buttons, active navigation

Typography (Google Fonts):

Fonts are loaded in index.html:

  • Plus Jakarta Sans — Body text, interface buttons, and inputs.
  • Playfair Display — Elegant serif headings for handcrafted branding.
  • Outfit — Metric counters and modern price tags.

6. Editing Products, Categories & Blogs

All demo data is organized into clean JavaScript files in src/data/. You can easily add, edit, or delete items:

1. Products (src/data/products.js)

Each product object contains:

{
  id: 1,
  title: "Handmade Velvet Crochet Bear",
  category: "Decor & Gifts",
  price: 1299,
  originalPrice: 1599,
  img: "/uploads/products/decor/crochet-bear.jpg",
  rating: 4.9,
  reviewsCount: 48,
  badge: "Bestseller",
  material: "100% Velvet Yarn with hypoallergenic polyfill",
  description: "Lovingly hand-crocheted plush bear with safety eyes.",
  inStock: true,
  stockQuantity: 15,
  dimensions: "28cm (H) x 18cm (W)",
  featured: true
}

2. Categories (src/data/categories.js)

To add or change categories, modify the category list with an emoji icon and cover image:

{
  name: "Decor & Gifts",
  slug: "decor-gifts",
  icon: "🧸",
  description: "Charming amigurumi and handcrafted home accents.",
  image: "/uploads/categories/decor.jpg",
  featured: true,
  displayOrder: 1
}

3. Blogs (src/data/blogs.js)

Articles support structured content blocks (paragraph, tip, quote, image) and comment threads.

8. Connecting Any Live Backend API

If you build or connect your own backend API (Node.js, Express, Firebase, Supabase, Laravel, Django, Python FastAPI, etc.):

  1. Create a .env file in the frontend/ root: 
    VITE_API_URL=https://your-api-domain.com
  2. Inspect src/config/api.js where standard REST endpoint paths are defined: 
    export const API_ENDPOINTS = {
  PRODUCTS: `${API_BASE_URL}/api/products`,
  BLOGS: `${API_BASE_URL}/api/blogs`,
  ORDERS: `${API_BASE_URL}/api/orders`,
  CATEGORIES: `${API_BASE_URL}/api/categories`,
  CUSTOMERS: `${API_BASE_URL}/api/customers`,
  SETTINGS: `${API_BASE_URL}/api/settings`
};
  3. The src/services/dataService.js handles data fetching and automatically falls back to local storage if the API server is unreachable.

9. Admin Dashboard Overview

The template includes a full-featured Admin Studio accessible at /admin:

  • /admin — Executive Dashboard with revenue charts, total orders, and real-time activity log.
  • /admin/products — Product catalog manager with search, category filtering, stock adjustments, and soft-deletion.
  • /admin/categories — Category manager with emoji icons and product counts.
  • /admin/orders — Order fulfillment manager with 1-click status dropdowns (Processing, Shipped, Delivered).
  • /admin/customers — Customer directory with lifetime spend aggregator and order history.
  • /admin/blogs — Craft tutorial manager with spotlight toggles.
  • /admin/recycle-bin — Soft-delete safety net with 1-click restore for deleted products and articles.
  • /admin/settings — Store brand, email, phone, WhatsApp number, working hours, and social media links.
